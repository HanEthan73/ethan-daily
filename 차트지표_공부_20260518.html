📌 메인 지표 (차트 위에 직접 그려지는 것들)

1. 이동평균선 (MA — Moving Average)

"주가의 평균을 선으로 이어 추세의 방향을 보는 가장 기본적인 도구"

항목 내용
원리 n일간 종가 평균을 매일 계산해 이어 그림
종류 MA5(1주) / MA20(1달) / MA50(약 2.5달) / MA200(1년) / MA30W(주간 30주=약 7.5달)
골든크로스 MA50이 MA200을 위로 돌파 → 강세 전환 신호 → 매수 허가
데드크로스 MA50이 MA200을 아래로 이탈 → 약세 전환 → 매수 절대 금지
지지/저항 주가가 MA선에서 반등하면 "지지", 막히면 "저항"

4전략과의 관계:
- Weinstein: MA30W(주간 30주선) 위에서 거래 = Stage 2(상승) 확인
- VCP: MA50 기울기 우상향 확인 필수
- C&H: 컵 손잡이 구간이 MA50~MA200 사이에 위치하면 이상적

실전 활용 — 대표님 포트폴리오 기준:
- NVDA MA50 $222 → 현재가 $224 부근 = 지지선 근접 → 눌림목 진입 구간
- AMD MA50 < MA200 = 데드크로스 확인 → 추천 제외 (절대원칙)

2. 엔벨로프 (Envelope)

"MA 위아래에 일정 % 거리로 밴드를 그려 과매수/과매도 범위를 표시"

항목 내용
원리 보통 MA20 기준 ±5~10%에 상단/하단 선
읽는 법 상단 터치 = 단기 과매수 → 매도 고려 / 하단 터치 = 과매도 → 매수 고려

단점: 변동성이 큰 AI주(NVDA, ASTS)에서 밴드 폭이 고정되어 부정확. 볼린저밴드가 변동성을 동적으로 반영하므로 대체 가능 → OFF 권장

3. 볼린저밴드 (Bollinger Bands)

"변동성이 클수록 밴드가 벌어지고, 잠잠해지면 수축 — VCP 전략의 핵심 확인 도구"

항목 내용
구성 중심선(MA20) + 상단(MA20 + 2σ) + 하단(MA20 - 2σ)
σ(시그마) 표준편차: 가격이 평균에서 얼마나 퍼져 있는지 측정값
수축(Squeeze) 밴드 간격이 좁아짐 = 변동성 감소 = 폭발 직전 신호
팽창 밴드 간격이 벌어짐 = 강한 추세 진행 중
상단 터치 단기 과매수 경고 (RSI와 함께 확인)
하단 터치 과매도 → 반등 가능성

4전략과의 관계:
- VCP: 볼린저밴드 수축 = 변동성 수축 패턴 시각적 확인. 수축 후 거래량 폭발과 함께 상단 돌파 = 매수 진입 신호

실전 예시:

NVDA 볼린저밴드가 좁아지며 MA20($222) 부근에서 3주째 횡보 중이라면 → 조만간 방향성 폭발 임박. 거래량 급증과 함께 상단 돌파 시 VCP 진입 신호

4. 일목균형표 (Ichimoku Cloud)

"5가지 선이 동시에 지지·저항·추세·모멘텀을 표시하는 일본식 복합 지표"

선 이름 계산법 의미
전환선 (9일 고+저)/2 단기 중심가
기준선 (26일 고+저)/2 중기 중심가
선행스팬A (전환+기준)/2 → 26일 앞에 표시 구름 상단
선행스팬B (52일 고+저)/2 → 26일 앞에 표시 구름 하단
후행스팬 종가 → 26일 뒤에 표시 현재 모멘텀 확인

현실적 평가: 선이 너무 많아 AI주 단기 트레이딩에 노이즈만 추가. 4전략 프레임워크로 모든 기능이 커버됨 → OFF 권장

5. 매물대

"과거에 거래가 많이 몰렸던 가격 구간 — 실제 지지·저항선을 눈으로 바로 확인"

항목 내용
원리 가격대별 누적 거래량을 수평 막대로 표시
두꺼운 막대 그 가격에서 엄청나게 많은 사람이 매수/매도 = 강한 지지·저항
읽는 법 현재가 아래 두꺼운 매물대 = 지지선 / 위 = 저항선
매물대 돌파 대량 거래로 두꺼운 매물대를 뚫고 올라가면 → 다음 저항까지 빠른 상승 가능

실전 활용:

MU $715 아래에 매물대가 두껍다면 → 그 구간이 실질적 1차 지지선. 자동매수가($748/$725) 설정 근거가 됨

6. 추세선 (Trend Line)

"고점끼리, 저점끼리 이어 그린 수동 선 — 추세의 각도와 방향을 직관적으로 확인"

항목 내용
상승 추세선 저점들을 이어 그린 선 → 이 선 위에서 매수 유지
하락 추세선 고점들을 이어 그린 선 → 이 선 아래에서 매도/회피
돌파 추세선을 강한 거래량으로 돌파 = 추세 전환 신호

자동 계산이 아닌 수동 작업이므로 앱 알림 자동화와 무관. 참고 도구로만 활용.

📌 보조 지표 (차트 하단에 별도 패널로 표시)

7. MACD (Moving Average Convergence Divergence)

MACD: 이동평균 수렴·발산 지수 — 단기와 장기 추세의 벌어짐·좁혀짐으로 모멘텀 측정

"두 MA 선이 벌어지면 추세 강하고, 좁혀지면 약해진다는 신호"

구성요소 계산법 의미
MACD 선 EMA12 - EMA26 단기-장기 차이값
시그널 선 MACD의 EMA9 MACD의 평균선
히스토그램 MACD - 시그널 두 선의 간격 (막대로 표시)

EMA: Exponential Moving Average, 지수이동평균 — 최근 데이터에 더 큰 가중치

신호 읽는 법
골든크로스 MACD선이 시그널선 위로 교차 → 매수 신호
데드크로스 MACD선이 시그널선 아래로 교차 → 매도 신호
히스토그램 증가 추세 강화 중
히스토그램 감소 추세 약화 중 (주의)
다이버전스 주가는 신고점인데 MACD는 낮아짐 → 상승 약화 경고

4전략과의 관계:
- Weinstein Stage 판단 보조: MACD가 0선 위 = 상승 추세 확인
- VCP 브레이크아웃 타이밍: MACD 히스토그램 급증과 동시에 볼륨 폭발 = 최적 진입

8. DMI (Directional Movement Index)

DMI: 방향성 운동 지수 — 추세의 방향과 강도를 동시에 측정

구성 의미
+DI 상승 압력 강도
-DI 하락 압력 강도
ADX 추세 강도 (방향 무관, 25 이상 = 강한 추세)
  • +DI > -DI 이면 상승 추세 / ADX > 25 이면 그 추세가 강하다
  • MACD로 같은 기능을 더 직관적으로 파악 가능 → OFF 권장

9. ATR (Average True Range)

ATR: 평균 실제 범위 — 일정 기간 주가의 평균 변동폭(달러/원 기준)

항목 내용
원리 매일 고점-저점 폭의 14일 평균값
용도 "이 종목은 하루에 평균 얼마 움직이나" → 손절가 설정 기준
활용 손절가 = 진입가 - (ATR × 2) 방식으로 기계적 설정

예시: NVDA ATR이 $8이면 → 손절가를 진입가 대비 $16(ATR×2) 아래에 설정

브리핑에서 직접 손절가를 제공하므로 차트에 띄울 필요는 낮음 → OFF 권장

10. 거래량 (Volume)

"하루에 실제로 거래된 주식 수 — 모든 기술적 분석의 실체 확인 도구"

항목 내용
거래량 급증 + 상승 강력한 매수세 = 진짜 상승 신호
거래량 급증 + 하락 강력한 매도세 = 추세 전환 경고
거래량 감소 + 횡보 VCP 수축 구간 = 폭발 직전
거래량 없는 상승 신뢰도 낮음 — "속임수 상승" 가능성

4전략과의 관계:
- VCP: 변동성 수축 시 거래량도 점진적 감소 → 돌파 시 평균 대비 2~3배 이상 폭발 확인 필수
- C&H(컵앤핸들): 컵 바닥 형성 시 거래량 낮음 → 핸들 돌파 시 거래량 폭발 = 완벽한 매수 신호

11. CCI (Commodity Channel Index)

CCI: 상품 채널 지수 — 현재가가 통계적 평균 대비 얼마나 벗어났는지 측정

  • +100 이상 = 과매수 / -100 이하 = 과매도
  • RSI가 같은 기능을 더 직관적으로 제공 → OFF 권장

12. OBV (On-Balance Volume)

OBV: 온밸런스 거래량 — 상승일 거래량은 더하고 하락일은 빼는 누적 지표

신호 의미
OBV 상승 + 주가 횡보 세력 매집 중 → 조만간 주가 상승
OBV 하락 + 주가 횡보 세력 분산 중 → 주가 하락 선행

실제로는 거래량 차트로 직접 확인하는 편이 더 직관적 → OFF 권장

13. MFI (Money Flow Index)

MFI: 자금 흐름 지수 — 거래량을 가격과 결합한 "거래량 가중 RSI"

  • 0~100 척도, 80 이상 과매수 / 20 이하 과매도
  • RSI + 거래량 차트를 동시에 보면 MFI 없이도 동일한 판단 가능 → OFF 권장

📌 모멘텀 지표 (보조 패널에 추가 표시)

14. 모멘텀 (Momentum)

"n일 전 가격과 오늘 가격의 차이 — 상승 속도가 빠른지 느린지"

  • 0 이상 = 상승 중 / 0 이하 = 하락 중
  • ROC의 절대값 버전. 둘 다 있으면 중복 → OFF 권장

15. ROC (Rate of Change)

ROC: 변화율 — n일 전 대비 현재 가격 변화율(%)

  • 모멘텀의 % 표현. MACD로 훨씬 풍부한 정보 제공 가능 → OFF 권장

16. RSI (Relative Strength Index)

RSI: 상대 강도 지수 — 일정 기간 상승폭과 하락폭의 비율로 과매수/과매도 측정 (0~100)

"주가가 너무 많이 올랐나, 너무 많이 내렸나를 숫자로 보여주는 온도계"

구간 의미 전략 적용
RSI > 70 과매수 — 단기 조정 가능성 신규 진입 자제 / 기존 보유자 일부 익절 고려
RSI 50~70 정상 상승 구간 매수 유지
RSI 30~50 약세 전환 경고 손절 준비
RSI < 30 과매도 — 반등 가능성 눌림목 매수 기회 탐색

4전략과의 관계:
- VCP: RSI가 과매수에서 식히면서 MA 눌림목 = 최적 진입 구간
- 브리핑에서 항상 "RSI 77 → 과매수, 눌림목 대기" 식으로 활용하는 바로 그 지표

실전 예시 (브리핑 그대로):

"NVDA 현재가 $224, RSI 77(단기 과매수). MA20($215~222) 눌림목이 이상적 진입 구간. RSI 60 이하로 식을 때까지 기다려야 할 종목."

17. 스토캐스틱 (Stochastic)

Stochastic: 최근 n일 고점-저점 범위 내에서 현재가의 상대적 위치 (0~100)

구성 의미
%K선 현재 위치 (빠른 선)
%D선 %K의 이동평균 (느린 선)
80 이상 과매수
20 이하 과매도

RSI와 거의 동일한 기능. RSI 하나면 충분 → OFF 권장

18. William's R

Williams %R: 스토캐스틱의 반전판. 0 ~ –100 척도

  • –20 이상 = 과매수 / –80 이하 = 과매도
  • 스토캐스틱을 뒤집어 놓은 것. RSI 있으면 완전 중복 → OFF 권장

19. TRIX

TRIX: Triple Exponential Average — EMA를 3번 겹쳐 계산한 변화율 (잡음 제거 특화)

항목 내용
원리 EMA → EMA → EMA 3번 평활화 후 전일 대비 변화율
장점 일반 MA보다 잡음(noise) 제거 효과 탁월
단점 너무 느림 — 신호 지연이 커서 단기 트레이딩에 부적합
신호 0선 위 = 상승 추세 / 0선 아래 = 하락 추세
