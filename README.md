# ETHAN MAIL — Gmail + 네이버 메일 통합 앱 (아이폰 전용, PC 불필요)

> **한 줄 요약** — 두 우체통(Gmail·네이버)을 클라우드 서랍 하나에 모으고, 아이폰 홈 화면 아이콘으로 열어서 "채용" 같은 색인 탭으로 관련 편지만 뽑아 보는 앱.

## 1. 기능

| 구분 | 내용 |
|---|---|
| 통합 메일함 | Gmail·네이버 받은/보낸 메일을 시간순 한 화면에 (계정 색 배지) |
| 색인 탭 | 제목·본문·보낸사람·받는사람 전체를 FTS5 색인에서 검색 → 키워드 묶음별 탭 |
| 탭 문법 | `채용, 면접` · `from:saramin` · `to:hr@` · `subject:합격` · 제외 키워드 |
| 탭 저장 | 아이폰에 저장 → 서버가 재시작돼도 유지 |
| 쓰기 | 계정 선택 발송, 답장·전체답장·전달(원본 첨부 포함), 사진·파일 첨부 |
| 보안 | 주인 Gmail로만 연결 가능, 8회 실패 시 15분 잠금, 계정 정보는 폰에만 저장 |
| 속도 | 최신 메일부터 받음, 큰 첨부는 누를 때 다운로드 |

## 2. 폰으로 배포하기

| 단계 | 할 일 |
|---|---|
| ① 배포 | Koyeb 원클릭 배포 링크 → GitHub로 로그인(카드 등록) → **Deploy** |
| ② 열기 | 발급된 `https://○○○.koyeb.app` 을 Safari로 열기 |
| ③ 계정 연결 | Gmail 주소·앱 비밀번호, 네이버 주소·애플리케이션 비밀번호 입력 → **연결하기** (최초 1회, 폰에 저장) |
| ④ 홈 화면 | Safari 공유 → **홈 화면에 추가** |

- 서버 환경변수 입력 불필요. 계정 정보는 폰에만 저장되고, 서버가 잠들었다 깨면 폰이 자동으로 다시 연결합니다.
- 주인 Gmail 계정(해시로 고정)으로 로그인에 성공해야만 연결되므로, 주소를 알아도 남은 쓸 수 없습니다.
- 선택 환경변수: `INITIAL_SYNC_COUNT`(기본 300), `NAVER_APPEND_SENT=0`(보낸 메일 중복 시)

## 3. 무료 서버 특성

| 항목 | 내용 |
|---|---|
| 잠자기 | 약 1시간 사용 없으면 서버가 잠듦 → 다음 실행 때 몇 초 깨우고, 최근 메일을 다시 받는 동안(1~2분) 목록이 위에서부터 채워짐 |
| 탭 | 폰에 저장되므로 영향 없음 |
| 메일 원본 | Gmail·네이버 서버에 그대로 있음 (이 앱은 삭제 기능 없음, 읽음 표시만 반영) |

## 4. 체험·로컬 실행 (선택)

| 방법 | 명령 |
|---|---|
| 데모 | `python app.py --demo` (샘플 메일 16통) |
| PC 실행 | `config.json` 또는 위 환경변수 설정 후 `python app.py` |
