# ETHAN MAIL — Gmail + 네이버 메일 통합 앱 (아이폰 전용, PC 불필요)

> **한 줄 요약** — 두 우체통(Gmail·네이버)을 클라우드 서랍 하나에 모으고, 아이폰 홈 화면 아이콘으로 열어서 "채용" 같은 색인 탭으로 관련 편지만 뽑아 보는 앱.

## 1. 기능

| 구분 | 내용 |
|---|---|
| 통합 메일함 | Gmail·네이버 받은/보낸 메일을 시간순 한 화면에 (계정 색 배지) |
| 색인 탭 | 제목·본문·보낸사람·받는사람 전체를 FTS5 색인에서 검색 → 키워드 묶음별 탭 |
| 탭 문법 | `채용, 면접` · `from:saramin` · `to:hr@` · `subject:합격` · 제외 키워드 |
| 탭 저장 | 아이폰에 저장 → 서버가 재시작돼도 유지 |
| 쓰기 | 계정 선택 발송, 답장·전체답장·전달(원본 첨부 포함), 사진·파일 첨부 |
| 보안 | 접속 비밀번호 로그인(180일 유지, 8회 실패 시 15분 잠금), 메일 앱 비밀번호는 서버 Secret에만 저장 |
| 속도 | 최신 메일부터 받음, 큰 첨부는 누를 때 다운로드 |

## 2. 폰으로 배포하기 (약 15분)

| 단계 | 할 일 |
|---|---|
| ① 앱 비밀번호 | Gmail: Google 계정 → 보안 → 2단계 인증 → **앱 비밀번호**<br>네이버: 메일 환경설정 → POP3/IMAP → **IMAP/SMTP 사용함** + 보안설정 → **애플리케이션 비밀번호** |
| ② GitHub | 이 코드가 든 Private 저장소 `ethan-mail` |
| ③ Koyeb 가입 | koyeb.com → GitHub로 가입 → 카드 등록(무료 플랜, 확인용 임시 승인 후 취소) |
| ④ 서비스 생성 | Create Service → GitHub → `ethan-mail` → Builder **Dockerfile** → Instance **Free** → Port **8000** |
| ⑤ 환경변수 | 아래 표 입력 (비밀번호류는 Secret으로) |
| ⑥ 배포 | Deploy → 발급된 `https://○○○.koyeb.app` 주소를 Safari로 열기 |
| ⑦ 홈 화면 | Safari 공유 버튼 → **홈 화면에 추가** → 아이콘으로 실행 |

### 환경변수

| 이름 | 값 | 필수 |
|---|---|---|
| `APP_PASSWORD` | 이 앱에 들어갈 때 쓸 비밀번호 (길게) | ✅ |
| `GMAIL_EMAIL` | Gmail 주소 | ✅ |
| `GMAIL_APP_PASSWORD` | Google 앱 비밀번호 16자리 | ✅ |
| `NAVER_EMAIL` | 네이버 메일 주소 (전체 주소) | ✅ |
| `NAVER_APP_PASSWORD` | 네이버 애플리케이션 비밀번호 | ✅ |
| `MY_NAME` | 보내는 사람 이름 (예: 한의성) | 선택 |
| `INITIAL_SYNC_COUNT` | 메일함당 가져올 최근 메일 수 (기본 300) | 선택 |
| `NAVER_APPEND_SENT` | 보낸 메일이 2통씩 보이면 `0` | 선택 |

## 3. 무료 서버 특성

| 항목 | 내용 |
|---|---|
| 잠자기 | 약 1시간 사용 없으면 서버가 잠듦 → 다음 실행 때 몇 초 깨우고, 최근 메일을 다시 받는 동안(1~2분) 목록이 위에서부터 채워짐 |
| 탭 | 폰에 저장되므로 영향 없음 |
| 메일 원본 | Gmail·네이버 서버에 그대로 있음 (이 앱은 삭제 기능 없음, 읽음 표시만 반영) |

## 4. 체험·로컬 실행 (선택)

| 방법 | 명령 |
|---|---|
| 데모 | `python app.py --demo` (샘플 메일 16통) |
| PC 실행 | `config.json` 또는 위 환경변수 설정 후 `python app.py` |
