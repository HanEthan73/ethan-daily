② 네이티브 앱 + 위젯 처음 한 번 PC 필요

SideStore로 설치합니다. 처음 설정만 PC로 하고, 그 뒤 업데이트와 7일 갱신은 아이폰에서 처리됩니다.

  1. PC(Windows/Mac)에서 sidestore.io 설치 가이드대로 SideStore 설치(페어링 파일 만들기 포함)
  2. 아이폰 SideStore → Sources → + → 아래 주소 붙여넣기
  3. 목록에 뜬 ETHAN MEMO → Free(설치)
  4. 홈 화면 길게 누름 → 편집 → 위젯 추가 → ETHAN MEMO
